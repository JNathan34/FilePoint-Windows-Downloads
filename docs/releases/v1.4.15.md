## What’s new

- **Start with Windows.** Enable this option in FilePoint’s three-dot menu to launch it in the system tray when you sign in to Windows.
- **Keep me signed in.** Select **Keep me signed in on this PC** when you sign in. FilePoint uses Windows encryption to store your sign-in and can reconnect when it opens. Your server may still ask for a new verification code.
- **Reopen after updates.** Future in-app updates started from 1.4.15 reopen FilePoint automatically after Setup finishes.
- **Three-dot menu.** The Options button shows three matching dots. Available updates are listed inside the menu.

If you’re updating from 1.4.11, open FilePoint once after installing this release. Select **Open FilePoint** in Setup or start it from the Start menu.
