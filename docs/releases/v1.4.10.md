## What’s new

- **Delete from Explorer.** Deleted files and folders go to the FilePoint web app’s Recycle Bin when your server supports it.
- **Move between FilePoint sources.** Cut and paste files and folders between writable sources in Explorer. Explorer copies the items and FilePoint recycles the originals.
- **Copy folders with custom icons.** Explorer can still display the icons. Generated icon files stay out of normal folder copy and delete operations.
- **Replace files in Explorer.** FilePoint handles case-insensitive destination names and moves with replacement enabled when the destination is empty.

Windows permission and metadata changes are limited, and applications that save with the Windows `ReplaceFile` API may be unable to save directly to the drive.
