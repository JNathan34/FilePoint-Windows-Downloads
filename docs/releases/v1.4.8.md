## What’s new

- **Save from Explorer.** Create files and folders, edit files, and rename or move items within a writable source when your FilePoint server enables Windows writes.
- **Recover unsaved changes.** If a save fails or conflicts with a newer server copy, FilePoint keeps the local copy and shows **Open Unsaved Uploads** in the tray menu.
- **More reliable updates.** FilePoint preserves Setup’s original filename for the Windows installer cache and starts Setup before closing the app.

If the update button in your current version closes without starting Setup, quit FilePoint from the tray and run the installer below once.

| Your PC | Installer |
| --- | --- |
