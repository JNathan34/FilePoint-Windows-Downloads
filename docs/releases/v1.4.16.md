## What’s new

- **Smaller tray menu.** The FilePoint tray menu uses a narrower layout with a shorter header and closer spacing.
- **Install updates from the tray.** FilePoint dismisses the tray menu before opening the update window, so the install button can receive input.

Use **Updates** in the three-dot menu to install this release if the tray update button is unresponsive in your current version.
